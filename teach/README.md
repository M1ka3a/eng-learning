# Teach SE workspace

This repository's teaching workspace is this `teach/` directory, resolved automatically by the project-local `$teach-se` Skill from the repository root. The actual Go project is the parent directory.

- Route topics through [TOPICS.md](TOPICS.md); each topic's `TOPIC.md` owns its knowledge map and links to topic-local lessons, Labs, and references.
- [MISSION.md](MISSION.md), [RESOURCES.md](RESOURCES.md), and [NOTES.md](NOTES.md) are shared across topics.
- `../learning/STATE.md` is the sole source of project progress and capability evidence; `../learning/SESSIONS.md` is the chronological history. Do not duplicate them in topic folders.
- Follow the Skill at [`.agents/skills/teach-se/SKILL.md`](../.agents/skills/teach-se/SKILL.md). `WORKFLOW.md` is only a pointer for backward compatibility.
