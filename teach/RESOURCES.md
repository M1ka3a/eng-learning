# Engineering and AI Agent Resources

## Knowledge

- [Effective Go](https://go.dev/doc/effective_go)
  Official guidance on idiomatic Go, formatting, interfaces, and error handling. The page notes that it is not actively updated, so use it for core idioms and check current library or language details in current official docs.
- [Go Concurrency Patterns: Context](https://go.dev/blog/context)
  Go team's explanation of cancellation, deadlines, and request-scoped propagation. Use when extending the current project's context and worker lifecycle work.
- [Go context package](https://pkg.go.dev/context)
  Current package API reference for context values, cancellation, and deadlines; use alongside the conceptual article when implementing.
- [PostgreSQL SELECT](https://www.postgresql.org/docs/current/sql-select.html)
  Primary reference for row locking and `SKIP LOCKED`; the documentation specifically describes its use for queue-like consumers and its inconsistent-view tradeoff.
