# Teaching preferences

- Coach in Chinese. Use English for mock interviews, the project pitch, and behavioral answers. Bilingual HTML lessons are optional and only on request.
- Teach before testing on new topics: explanation, then example, then 1–2 checks. Opening with judgment questions on an unseen topic overloaded the learner on 2026-11-16.
- After one attempt, give the answer directly.
- Python for algorithms and test automation, Go for the service. Never practice the same skill in both.
- The Agent may implement; the learner must be able to explain it.
