# Teaching preferences

- Treat AI Agents as collaborators in engineering delivery. Teach how to frame work, review generated changes, challenge assumptions, and verify outcomes; do not make unaided hand-writing the goal.
- Make lesson content bilingual by default: pair Chinese explanations with aligned English counterparts for the core concepts and takeaways, retaining standard English technical terminology. Keep conversational coaching Chinese-first unless the learner asks otherwise.
- Connect Go syntax to the project's backend behavior, system modeling, architecture, technology selection, reliability, and operations when relevant.
- Scale teaching to the actual problem. Use an exercise or retrieval check when it adds value; do not prescribe a fixed long session or exercise for every topic.
- Use `../learning/STATE.md` and recent entries in `../learning/SESSIONS.md` for current progress and evidence. Do not keep a parallel progress summary here.
- Claim durable understanding only when supported by the learner's explanation or demonstrated reasoning.
