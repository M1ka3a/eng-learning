# Software Implementation

Knowledge map for building maintainable software with AI Agent support and accountable human review. Verified capability evidence lives in [learning/SKILLS.md](../../../learning/SKILLS.md).

## Knowledge map

1. Go semantics, standard library, errors, and package structure
2. API contracts and boundary validation
3. Interfaces, dependency direction, and modularity
4. Readability, resource lifecycles, and refactoring
5. Agent task framing, scoped implementation, and diff inspection
6. Code review for correctness, security, maintainability, and operations

Prerequisite path: trace behavior → scope a change → inspect edge/failure paths → refactor against explicit quality goals.

- [Go documentation](https://go.dev/doc/) — official learning and reference entry.
- [Effective Go](https://go.dev/doc/effective_go) — core idioms; consult current docs for newer features.
