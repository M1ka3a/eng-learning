# Mission: Land an SDET/QA role in Singapore, with backend as a stretch

## Why

The learner has ~6 years of QA/SDET experience and is moving toward engineering-heavy roles. The near-term goal is an offer from a mid-size or larger company in Singapore. Primary targets are SDET and QA roles, which are the most realistic transition step. Backend (RD) roles at smaller companies are a secondary target. The learner already holds one QA offer from a small company, which provides a fallback.

## Timeline and budget

- Applications start **2026-11-19**. Interviews are expected to follow within a few weeks, so learning runs in parallel with interviewing.
- Study time: **4+ hours per day**.
- Resume: done. The learner has prior interview experience and some project preparation.

## What interviews test (initial weights; revise after each real interview)

| Area | SDET/QA weight | Backend weight |
|---|---|---|
| Algorithms (LeetCode Easy–Medium, Python) | High | High |
| Python (language and pytest/automation) | High | Medium |
| Test design, automation framework, CI/CD, flaky tests, test strategy | High | Low |
| Project deep-dive (this repo, English) | High | High |
| Behavioral (English) | High | Medium |
| Database (SQL, transactions, isolation, locks, indexes) | Medium | High |
| Go (language, concurrency, context) | Low–Medium | High |
| HTTP / networking basics | Medium | Medium |
| System design (light for SDET: "how would you test this system") | Medium | Medium |

## Language homes (to avoid mixing Python and Go)

- **Python:** all algorithm practice and all test automation.
- **Go:** the service in this repository.
- Do not practice the same skill in both languages. When a Python/Go difference matters (`None`/`nil`, exceptions/error returns, slicing, `=`/`:=`), point it out and add it to the question bank if the learner trips on it.

## Success looks like

- Common Medium problems, by pattern, solved in Python within ~30 minutes.
- This project is presentable and runnable, with a green CI. The learner can defend every line of it in English.
- Core SDET and backend questions answered clearly under follow-up.
- An SDET/QA offer from a mid-size or larger Singapore company.

## Out of scope for now

- AI platform, MCP, or agent-orchestration features in this project.
- New product features that do not improve the interview story.
- Polished bilingual HTML lessons by default.
